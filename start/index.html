Install R-CLI

Paste this into your terminal, then sign in and open any project.

curl -fsSL https://app.backboard.io/api/cli | bash
irm https://app.backboard.io/api/cli/windows | iex

Then

backboard login
cd your-project && backboard
Go to your dashboard

The source is on GitHub, MIT licensed.
